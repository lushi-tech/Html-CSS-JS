# Html-CSS-JS
This project is about creating an online business and it is about online courses. I called it "Virtual Academy".
I used the HTML to create the content, CSS to make it beautiful and JavaScript to handle information.
The website has these pages: Home page where the visitors geet the general information, Sign in page, Log in page, About and Contact page.
I also used the knowledge gained from DataBase to create tables for saving the information from the Log in and Sign in page. For connecting of website and Database I used PHP
